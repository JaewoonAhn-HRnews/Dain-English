# 다인의 영어 독서 노트

초등학생 다인이의 영어 독후감을 기록하고 첨삭받는 프로그램이에요.

## 주소 (GitHub Pages)

| 누가 | 주소 | 하는 일 |
|---|---|---|
| 다인 | `https://jaewoonahn-hrnews.github.io/Dain-English/` | 표지·공책 사진 찍어 아빠에게 보내기, 아빠가 보낸 첨삭 결과 보기 |
| 아빠 | `https://jaewoonahn-hrnews.github.io/Dain-English/dad/` | Claude 독서 노트로 바로 가기 (손글씨 읽기·첨삭·독후감 평가) |

## 휴대폰에 앱처럼 설치하기

- **아이폰**: 사파리에서 주소 열기 → 공유 버튼(□↑) → 홈 화면에 추가
- **안드로이드**: 크롬에서 주소 열기 → 메뉴(⋮) → 홈 화면에 추가 (또는 앱 설치)

다인이 쓰기장은 로그인 없이 쓰고, 한 번 열면 인터넷이 없어도 열려요.
기록은 다인이 휴대폰 안에만 저장돼요.

## 주고받는 순서

1. 다인: 쓰기장에서 표지·공책을 찍고 **아빠에게 보내기** → 카카오톡으로 파일 전송
2. 아빠: 독서 노트에서 **파일 가져오기** → 손글씨 자동 인식 → 확인 → 첨삭
3. 아빠: **다인이에게 보내기** → 카카오톡으로 파일 전송
4. 다인: 쓰기장 **내 책장**에서 **파일 고르기** → 첨삭 결과 보기

## 파일 구성

- `index.html` — 다인이 쓰기장 (PWA)
- `sw.js`, `manifest.webmanifest`, `*.png` — 홈 화면 설치·오프라인용
- `dad/index.html` — 아빠 독서 노트 바로가기
